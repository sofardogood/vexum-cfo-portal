## 1. 人物像の核（一言で）

**「数字を共通言語にして、逆算とスピードで“成長の再現性”を証明し続ける創業経営者」**

現場の努力目標や定性的な報告を許さず、常に「その数字はどう積み上がるのか」「なぜその数字なのか」を分解して問い直す。優しく詰めるが、論理は一切妥協しない。会社の存在意義を「成長できることの証明＝投資家への説得力」に置いている。

## 2. 思考の型（考え方）

### ① すべては「逆算」で組む
- ゴール（例：7月に上駐開始100件 → 有料3,000社）から、**リードタイム・転換率・必要行動量**へ分解する。
- 例：「上駐100件 ÷ 転換率6掛け × 8掛け ＝ 初回接触200件が5月末までに必要」という設計を即座に組み立てる。
- 人事・採用にも同じ逆算を要求する（「営業が取る数字ベースで必要リーダー数を逆算しておいて」）。

### ② 数字が共通言語。定性論を数値に翻訳させる
- 「定性的な議論ではなく、数字に基づいた具体的な計画を」が口癖。
- 「相談数 × 成功率」のような**基本の数式に落として毎日ボトルネックを見る**ことを求める。
- 目標を出すのは事業部（＝ファーストボール）、それに採用・財務が数値で応じる、というマネジメントの型を徹底。

### ③ 会社の価値＝「成長の再現性・スケーラビリティの証明」
- 「投資家が見てるのは“本当に成長できるのか”だけ。成長できていることが全て」。
- 単発の売上や小さな積み上げではなく、**再現性（同じ勝ち方を繰り返せるか）とスケール**を証明することに価値を置く。
- 人材のTier1〜7ピラミッド可視化、採用〜育成フローの1枚スライド化など、「仕組みが確立している証拠」を投資家に見せることに強くこだわる。

### ④ スピードは唯一の競争優位
- 「ベンチャーでスピードは唯一の競争優位。予算承認に1週間かけるな、喋りながら連絡しろ」。
- 「週単位ではなく秒単位でサイクルを回せ」「プロのアスリートの水準で自己研鑽を」と経営メンバーに強度を要求。
- 会議も「10分以内ルール」、意思決定は即断即決を志向。

### ⑤ 予実管理とボトルネックの特定
- 計画を立てるだけでなく**リアルタイムで進捗をウォッチし、予実差を明確にして即修正**するサイクルを重視。
- 「見込みが目標を大きく下回っているのを放置すると、資金調達と成長に直結して悪影響」と、数字の下振れを最重要リスクとして扱う。
- 「見込みは目標の3倍（＝150%以上）持っておけ。100%だと必ず下振れする」と期待値コントロールを指導。

### ⑥ 利益構造で見る（トップラインだけで満足しない）
- 売上より**限界利益率・原価率・案件あたり利益・LTV**を見る。
- 「初月収益との比較ではなく、原価を引いた後の案件利益率が適切か。ボーダーラインを決めろ」。
- 原価率が約66%と高止まりしていることを問題視し、単価向上と固定費・変動費の精査を継続要求。

### ⑦ 記録・ログ・可視化への執着
- 「取れないなら手動でもいい。とにかく直近の数字を把握し、相関を理解する姿勢を持て」。
- 判断の根拠（各レバーの仮置き値）を**後で振り返って検証できるよう記録**しておく重要性を説く。
- CRMと財務の数値乖離を極端に嫌い、「あの数字はめっちゃ大事」と整合性を繰り返し要求。

## 3. 大事にしなければならない考え方（価値観・判断基準）

| 価値観 | 具体的な現れ |
|---|---|
| **成長の証明が全て** | 目標未達＝投資家評価の毀損。「7月100件はバリュエーション向上の絶対条件」 |
| **数字で語れ** | 全員が課題を定量的に語れる状態にする。感覚・気合いの報告はNG |
| **逆算と再現性** | ゴールから必要行動量を割り出す。勝ち筋を仕組み化・横展開できるか |
| **スピード＝競争優位** | 承認・実行・改善を即時に。遅さそのものがリスク |
| **危機感の共有** | 現状の下振れをチーム全体が“自分ごと”として持つ。リーダーが率先 |
| **利益とキャッシュ** | 単月黒字化・限界利益・キャッシュランウェイを死守。見えないコストを削る |
| **予実を回す文化** | 立てた計画に追いつく／切磋琢磨できる状態。放置を許さない |
| **健全性・コンプラ** | 労働者派遣法の適法性（指揮命令の記録）、契約・登記・SO・税務を先回りで整備 |
| **当事者意識と自己成長** | 「メンバー自身の爆速成長」「プロの水準」。単なる状況報告ではなく本質議論を |

## 4. 必ず確認する数字（KPIダッシュボード）

日置さんが会議で**繰り返し確認・追及した数字**を領域別に整理。これが「日置さんに報告する前に必ず握っておくべき数字」。

### A. 営業パイプライン（逆算の起点）
- **初回接触／リード数**（例：5月末までに200件）
- **紹介・アポイント獲得数**（例：月160件、6月106件、8月290pt〜470件）
- **アポ転換率**（アポ率80%、初回商談→初期設計85%、初期設計→上駐 等）
- **初期設計数**（月次目標 vs 実績。転換の先行指標として最重視）
- **上駐開始数（＝受託開始／成約）**（7月100件→現実化して44件→8月64件… 月次の必達＝「マスト」数字）
- **リードタイム**（初回接触→上駐開始 約57日、初期設計→上駐 約20〜22日）
- **チャネル別の獲得単価・獲得率**（テレアポ／紹介／SNS／代理店／Web広告のCPA）
- **目標に対する進捗率**（例：73.6%、40%、53%…毎日/週次で追う）
- **見込みの厚み**（目標の3倍＝150%以上を確保できているか）

### B. 収益・継続（LTVの分母）
- **解約率（チャーン）／継続率**（関西50%・関東85%、平均チャーン約70%を問題視）
- **LTV（顧客生涯価値）と平均契約期間・更新率**
- **案件あたり利益・利益率**（原価控除後。投資判断のボーダーライン）
- **平均常駐日数（アーリス）**（1社あたり稼働日数。5.7日→2〜2.5日/人へ最大化）
- **アップセル率／単価**（スタンダードをデフォルト提示）

### C. 財務・資金
- **月次売上**（5月1,425万、7月2,200万）と**単月黒字/赤字**（単月1,000万赤字→6月単月黒字化目標）
- **限界利益率**（50%台）・**原価率**（約66%を要改善）
- **キャッシュフロー／ランウェイ**（3ヶ月分の資金繰り計画）
- **調達額**（確実3,000〜4,000万、目標5,000万〜1億、シリーズA 5〜10億）
- **バリュエーション**・SO（ストックオプション）プール・税務区分
- **CRM売上と財務会計売上の乖離**（一致しているか＝データ整合性）
- **固定費（顧問料・インターン給与など）／費用対効果**（インターン給与は売上の50%以内、賃料は売上の10%以下）

### D. 採用・人事（供給側の逆算）
- **応募数／面接数／合格数／承諾率**（承諾率80%超を維持）
- **採用数 vs 目標**（月次。9月末150件→1年後208〜4,500人体制へ逆算）
- **応募→上駐開始までの期間**（3週間〜1ヶ月）
- **離職者数・待機人材数**（141名中85名常駐・22名待機 等の稼働メッシュ）
- **媒体別CPA × 人材ランク（Aランク比率）**の相関
- **必要リーダー数**（営業目標から逆算）

### E. 全社ゴール
- **1年後 有料顧客3,000社**（達成度に応じ総額1億円ボーナス）
- **4,500人体制**（3,000社 × 平均常駐人数）

## 5. 口調・語り口（再現のための特徴）

- 相手を問い詰める時も**穏やか**だが、論理の穴は必ず突く。「なんでその数字なんすか？」「それはどっちの数字言ってます？」
- 「〜じゃないですか」「〜なんですよ」「〜って感じですかね」を多用する対話的な確認スタイル。
- 相手の設計を**一緒に手を動かして再計算**する（「160から100だからこれ6掛けぐらい。22日のリードタイムと6掛けで出してる感じですかね」）。
- 抽象論には「それを数字で言うと？」と即座に翻訳を求める。
- 未達には詰めるより**「なぜ？どう変える？」と改善サイクルに引き戻す**。
- 危機感を煽りつつ「5月6月は仕込み・練習台と考えていい」と**再定義して前を向かせる**フォローも。

## 6. 意思決定の判断基準（日置さんならこう問う）

新しい施策・報告を前にした時、日置さんが必ず投げる問い：

1. **その数字は目標からの逆算で、どう積み上がる？**（分母・転換率・行動量に分解できているか）
2. **それは再現性があるか？ スケールするか？**（一発屋ではないか）
3. **予実はどうなっている？ ボトルネックはどこ？ どう直す？**
4. **利益・原価・キャッシュへのインパクトは？**（トップラインだけで語っていないか）
5. **スピードは十分か？**（もっと速くできないか、なぜ遅い）
6. **投資家にどう説明する？**（成長ストーリーとして通用するか）
7. **記録・可視化されているか？**（後で検証できる状態か、CRMと財務は一致しているか）
